

# Student Registration Form

## Project Overview

A web-based Student Registration Form developed using Python and Django. The application allows users to enter and manage student information through a simple web interface.

## Technologies Used

- Python
- Django
- HTML
- SQLite

## Key Features

- Student registration using a web form.
- Collects student name, email, phone number, course, and skills.
- Provides a Save button to submit student details.
- Uses Django for backend processing.
- Uses SQLite for database storage.

## How to Run

1. Clone the repository:

   `git clone https://github.com/Sahanatc3214/Student-Registration-Form.git`

2. Open the project folder:

   `cd Student-Registration-Form`

3. Install Django:

   `pip install django`

4. Apply database migrations:

   `python manage.py migrate`

5. Start the development server:

   `python manage.py runserver`

6. Open `http://127.0.0.1:8000/` in your browser.
